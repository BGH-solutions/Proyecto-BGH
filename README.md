# S.I.G.S.M. - Sistema Informático de Gestión de Servicios Médicos 

Este proyecto consiste en un módulo desarrollado para el Hospital de Clínicas, diseñado para optimizar recursos mediante la digitalización de documentos informativos impresos. El sistema permite a los pacientes acceder a indicaciones médicas y completar encuestas de satisfacción de forma digital escaneando un código QR desde sus dispositivos móviles.

## Características Principales
* **Módulo Administrativo:** Integrado al panel central del hospital, permite al personal administrativo cargar y gestionar documentación.
* **Acceso Móvil para Pacientes:** Los usuarios pueden visualizar los documentos desde cualquier pantalla móvil escaneando un código QR único por archivo.
* **Módulo de Encuestas:** Formularios de satisfacción (anónimos o segmentados) cuyas respuestas se almacenan en el servidor para calcular indicadores de calidad.

## Tecnologías Utilizadas
* **Backend:** PHP 8.5.
* **Base de Datos:** MySQL. 
* **Frontend:** Bootstrap 5.3. 
* **Entorno de Desarrollo:** Visual Studio Code.
* **Control de Versiones:** Git y GitHub.
